# WhaleTranslator

WhaleTranslator는 Whale Browser를 포함한 Chromium 브라우저에서 선택한 텍스트나 현재 페이지를 OpenAI 호환 번역 API로 번역하는 Manifest V3 확장 프로그램입니다. 여러 프로바이더 프로필을 저장하고 기본 프로바이더와 fallback 순서를 지정할 수 있습니다.

Discord 클라이언트 플러그인으로 옮길 때 필요한 동작 계약과 구조는 [Discord 플러그인 포팅 가이드](docs/DISCORD_PORTING.md)에 정리되어 있습니다.

## 준비

- Node.js 22.13 이상
- OpenAI 호환 API의 Base URL, 모델 ID, API 키
- Whale Browser 또는 Chromium 기반 브라우저

새 설치에는 다음 세 프로필이 기본으로 준비됩니다. API 키는 포함되지 않으며 직접 발급받아 입력해야 합니다.

- 기존 기본 API: `http://100.115.209.7:4323/v1` / `deepseek-v4-flash`
- [Groq 무료 티어](https://console.groq.com/keys): `https://api.groq.com/openai/v1` / `qwen/qwen3.8-27b` (Preview)
- [NVIDIA NIM 무료 엔드포인트](https://build.nvidia.com/deepseek-ai/deepseek-v4-flash-0731): `https://integrate.api.nvidia.com/v1` / `deepseek-ai/deepseek-v4-flash-0731`

무료 사용량과 모델 제공 여부는 각 서비스의 정책에 따라 달라질 수 있습니다. 실제 요청은 각 프로필의 Base URL 뒤에 `/chat/completions`를 붙인 주소로 전송됩니다. 별도의 `.env` 파일은 사용하지 않습니다.
기존 설치에는 확장 업데이트 시 Groq와 NVIDIA NIM 프로필을 한 번만 추가합니다. 같은 ID의 프로필이 이미 있으면 유지하며, 추가된 프로필을 사용자가 삭제한 뒤에는 자동으로 복원하지 않습니다.

## 빌드 및 설치

```bash
npm install
npm run build
```

Whale의 확장 프로그램 관리 화면에서 개발자 모드를 켜고, `압축해제된 확장 앱 설치`를 선택한 다음 이 프로젝트의 `dist` 폴더를 지정합니다.

확장 아이콘을 누른 뒤 다음 설정을 저장합니다.

1. 프로바이더 이름
2. OpenAI 호환 API Base URL
3. 모델 ID와 API 키
4. 기본 프로바이더와 fallback 순서
5. 기본 도착 언어. 최초 기본값은 한국어입니다.

`추가`로 프로바이더 프로필을 여러 개 만들 수 있습니다. 프로필 목록 선택은 편집 대상을 바꾸며, 번역 경로에서 기본 프로바이더와 fallback 순서를 별도로 지정합니다. 키가 없는 프로필은 건너뛰고, 인증·요청 제한·네트워크·서버·응답 형식 오류가 번역 출력 전에 발생하면 다음 프로바이더를 시도합니다. 출력이 시작된 뒤에는 서로 다른 프로바이더의 결과가 섞이지 않도록 fallback하지 않습니다. `연결 테스트`는 편집 중인 프로필에만 매우 짧은 확인 요청을 보냅니다. 저장된 키는 다시 화면에 표시되지 않습니다.
`삭제`는 선택한 프로필을 즉시 제거하고, 기본 프로바이더를 삭제한 경우에는 첫 번째 fallback 프로바이더를 새 기본값으로 지정합니다.

## 사용법

- 확장 아이콘 → `페이지 번역`: 저장된 프로바이더와 도착 언어로 현재 페이지를 번역합니다. 페이지에 표시되는 진행 상태에서 중지·재시도할 수 있고, 팝업이나 페이지 상태 표시의 `원문 보기`로 복원할 수 있습니다. 설정을 변경했다면 먼저 `설정 저장`을 눌러 주세요.
- `Alt + T`: 선택한 텍스트 바로 아래에 번역 창을 엽니다. 아래 공간이 부족하면 위쪽에 표시하고, 선택 영역이 없으면 화면 오른쪽 위에 빈 번역 창을 엽니다. 선택한 텍스트로 열면 원문 편집 영역은 접힌 상태로 시작하며, 하단의 `∨` 버튼으로 펼칠 수 있습니다.
- `Alt + Shift + T`: 현재 페이지의 표시 가능한 일반 텍스트를 번역문으로 교체합니다. 다시 누르면 저장해 둔 원문을 복원합니다.
- 패널 안 `Ctrl + Enter` 또는 `Command + Enter`: 입력한 원문 번역
- `Escape`: 사전 창이 열려 있으면 사전 창을, 아니면 번역 창을 닫기

브라우저나 운영체제의 기존 단축키와 충돌하면 확장 설정 팝업의 `단축키 관리`에서 조합을 변경할 수 있습니다. macOS에서 `Alt`는 Option 키입니다.

## 패널 기능

- 원문 언어 자동 감지
- 14개 도착 언어
- 스트리밍 번역과 요청 중지
- 원문·번역문 음성 읽기
- 원문·번역문 글자 수
- 번역문 복사
- 접었다 펼칠 수 있는 원문 편집 영역
- 단어 사전: 번역문이나 원문에서 단어·짧은 구를 드래그하면 `사전` 버튼이 나타나고, 누르면 별도의 사전 창이 열립니다
- 헤더 드래그로 창 이동, 우측 아래 핸들로 크기 조절
- 이동·크기 조절 컨트롤에 포커스한 뒤 방향키로 16px, `Shift + 방향키`로 48px씩 조절
- 번역 창 바깥 웹페이지 클릭·스크롤·텍스트 선택
- 네트워크, 인증, 요청 제한, 서버 및 응답 형식 오류 안내

## 단어 사전

번역 창 안에서 60자 이하의 텍스트를 선택하면 선택 영역 아래에 `사전` 버튼이 나타납니다. 버튼을 누르면 설정한 프로바이더(LLM)에 선택한 단어와 주변 문맥을 함께 보내 사전 항목을 생성하고, 다음 내용을 도착 언어로 보여 줍니다.

- 표제어, 발음, 품사
- 문맥에서 쓰인 대표 의미와 용례 태그(historical, literary, standard 등)
- 그 밖의 의미 목록
- 원어 예문과 번역. 문맥에 있던 문장을 우선 사용합니다.

사전 창은 번역 창과 별도로 이동·크기 조절할 수 있으며, 번역 창의 fallback 프로바이더 순서를 그대로 따릅니다. 응답이 JSON 형식을 지키지 않으면 `다시 시도`로 재요청할 수 있습니다. 선택한 텍스트와 앞뒤 최대 600자의 문맥이 프로바이더로 전송됩니다.

## 권한과 개인정보

WhaleTranslator는 `activeTab`, `scripting`, `storage` 권한을 사용합니다. 기존 기본 API 호스트 외에 Groq와 NVIDIA NIM을 포함한 원격 프로바이더를 API 키와 함께 저장하거나 테스트할 때는 해당 HTTP(S) 호스트에 대한 선택적 접근 권한을 사용자에게 요청합니다. 키가 비어 있는 기본 프로필만으로는 접근 권한을 요청하지 않습니다. 모든 웹사이트를 상시 읽는 `<all_urls>` 권한은 사용하지 않습니다. 사용자가 팝업의 페이지 번역·원문 보기 버튼이나 확장 단축키를 누른 현재 탭에만 콘텐츠 런타임을 주입합니다.

번역을 실행하면 선택하거나 입력한 텍스트 또는 페이지의 번역 대상 텍스트가 기본 프로바이더로 전송됩니다. 사전 기능을 사용하면 선택한 단어와 주변 문맥도 같은 경로로 전송됩니다. fallback 조건이 발생하면 같은 텍스트가 설정한 순서의 다음 프로바이더로 전송될 수 있습니다. 프로바이더별 API 키는 `chrome.storage.local`에 저장되고, 서비스 워커만 읽습니다. 페이지와 콘텐츠 스크립트에는 키를 전달하지 않습니다. 브라우저 확장 로컬 저장소는 운영체제 키체인과 동일한 보안 저장소가 아닙니다.

## 전체 페이지 번역 범위

다음 내용은 번역하지 않습니다.

- `script`, `style`, `code`, `pre`, 폼 입력 영역
- 숨김·편집 가능·`translate="no"` 콘텐츠
- 이미지, SVG, canvas 내부 텍스트
- 브라우저 설정 화면과 내장 PDF 뷰어
- 교차 출처 iframe 내부 콘텐츠
- 번역 시작 후 동적으로 추가된 콘텐츠

페이지 애플리케이션이 번역 도중 해당 DOM 노드를 교체하거나 텍스트를 수정하면 그 노드는 안전하게 건너뜁니다. 복원할 때도 페이지가 자체적으로 갱신한 텍스트는 덮어쓰지 않습니다. 새로고침이나 페이지 이동 후에는 번역 상태가 유지되지 않습니다.

한 번에 실행하려면 `npm run check`를 사용합니다. 번역 패널 미리보기는 `npm run dev` 실행 후 `/preview.html?state=success`에서 확인할 수 있으며 `idle`, `streaming`, `error`, `missing-key` 상태와 사전 창을 보여 주는 `dictionary`, `dictionary-loading` 상태를 지원합니다. 프로바이더 설정 컨트롤의 8개 상호작용 상태는 `/provider-preview.html`에서 확인할 수 있습니다.
